## Date Basics – Java

### Descrizione
Esercizi Java di base dedicati alla gestione delle date.
Il progetto serve per prendere confidenza con i concetti fondamentali legati al tempo e alle operazioni sulle date.

### Cosa fa il progetto
- Creazione e stampa di date
- Utilizzo di date nel flusso del programma
- Esempi di logica basata su date

### Argomenti trattati
- Gestione delle date in Java
- Variabili e tipi di dato
- Logica sequenziale e condizionale
- Struttura di un programma Java

### Come eseguirlo
1. Clona il repository
2. Aprilo con IntelliJ
3. Avvia la classe che contiene il metodo `main`

### Obiettivo
Comprendere le basi della gestione delle date in Java e rafforzare la logica di programmazione.
